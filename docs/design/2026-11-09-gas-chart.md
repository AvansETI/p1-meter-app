# Gas chart on the Live page

## 1. Goal

Show gas use per hour for the last 24 hours on the Live page, for households with gas.

## 2. Data

`gas_delivered` is a cumulative counter (m³). DSMR 5 meters update it every 5 minutes, older
meters (DSMR ≤ 4) once per hour, a few minutes after the full hour.

**Hourly values:** for the 24 whole local hours ending with the current hour
(Europe/Amsterdam, DST-aware), value = counter at the end of the hour − counter at the end of
the previous hour.

```flux
from(bucket: B)
  |> range(start: <start of the hour 24 h ago, minus 1 h>)
  |> filter(fn: (r) => r._measurement == "dsmr" and r.signature == SIG and r._field == "gas_delivered")
  |> aggregateWindow(every: 1h, fn: last, createEmpty: true)
```

Post-processing in the API (same rule as architecture §7.4):

- hour without a counter value → `null` (no bar);
- first hour after one or more empty hours → the whole delta, with `spansGap: true` and
  `gapStart` (start of the first empty hour);
- negative deltas (counter reset/replacement) → `null`.

**Hourly-update detection:** among the counter increases in the last 24 h, if ≥ 3 increases
and ≥ 80 % of them fall in the first 10 minutes of an hour, the meter reports gas hourly
(`hourlyUpdates: true`).

## 3. API

`GET /api/v1/live/gas` (session required; 404 when the household has no gas)

```ts
GasSeries = {
  hourlyUpdates: boolean;
  hours: Array<{
    start: string;           // ISO, start of the local hour
    m3: number | null;       // null = no data
    spansGap?: true;
    gapStart?: string;
  }>;                        // 24 items, oldest first; the last one is the current hour
}
```

Cached 60 s per household, like `/live/recent`.

## 4. Web

- `GasChart` (ECharts bar chart, lazy-loaded with the power chart), one instance updated with
  `setOption` (lesson from #19), resized on visibility changes.
- Bars in `--app-data-gas`; gap bars hatched (decal pattern) at 50 % opacity.
- x-axis: hours (`HH:00`), every 6th label; y-axis m³ with 2 decimals; min 0.
- Tooltip: `14:00–15:00: 0,32 m³`; gap bar: `03:00–09:00: 1,24 m³ (niet uitgesplitst)`;
  with `hourlyUpdates`: extra line "Je meter geeft de gasstand één keer per uur door; verbruik
  verschijnt een uur later."
- Placement: section "Gas per uur" below "Afgelopen 24 uur" (mobile); on desktop the two
  charts side by side. Not rendered without `hasGas`.
- Refetch every minute (TanStack Query, like the other live data).
